# Udemy Clone 🎓

A responsive **Udemy-inspired website** created during my MERN Stack learning journey. This project focuses on recreating the look and feel of an online learning platform while strengthening my fundamentals in **HTML and CSS**.

## 📌 About the Project

This project is a frontend clone inspired by Udemy's website. I built it to practice creating structured layouts, designing reusable UI sections, and making web pages responsive across different screen sizes.

## ✨ Features

* 🎓 Udemy-inspired user interface
* 📚 Course listing and card layouts
* 🧭 Navigation bar and structured sections
* 📱 Responsive design
* 🎨 Clean and organized styling
* 💻 Built from scratch using HTML and CSS

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🎯 What I Learned

Through this project, I improved my understanding of:

* Responsive web design
* CSS Flexbox and layouts
* Page structure using semantic HTML
* Creating reusable UI patterns
* Styling and positioning elements
* Building user interfaces from a reference design
